## Approach
Extend the current evidence/guide/story schemas. Reuse an existing canonical place for new phases at the same building; introduce a distinct public location for genuinely different mapped features. Preserve the Chaco story identifier and all six guide URLs. Add contextual movies for the other five guides. Improve close-up chronology labels to identify the observation, not merely repeat the place name. Retain the existing world clock, topographic map, viewport filtering and overlap selection.

A narrative-only expansion would not meet the request for actual map detail. Invented building footprints or dates would overstate the sources. Separate public point observations with explicit temporal/spatial precision fit the established atlas and can later support surveyed geometry.
