User explicitly chose implementation now alongside the researched workbook.

Goal: import and display independently toggled conflict and trade overlays with temporal bounds and full evidence pages, fully offline.

Architecture: optional overlay metadata on the existing evidence/proposal record reuses claims, bibliography, review, storage and sharing. The Overlays worksheet uses the Evidence columns plus overlay_type, geometry_basis, geometry_geojson, geometry_precision and geometry_source. Point and LineString geometries only in this release; a schematic line represents an evidenced connection, not a reconstructed itinerary. Geometry may be null (unmapped). Approaches: a separate overlay database would duplicate evidence and proposal handling. Reusing movement records would conflate trade with migration. Optional explicit overlay metadata preserves the existing workflow and scientific distinction.
