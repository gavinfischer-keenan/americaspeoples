# Canada, Aleutians and readable illustrated guides

User direction: continue improving list-heavy deep-dive pages with real history, more individually licensed images and meaningful related links; substantially deepen the Aleutian Islands and coverage throughout Canada. Previously authorized independent judgment, master-map cross-referencing, Deep research budget, desktop/tablet priority and release workflow remain applicable.

## Approach and constraints

Reuse the existing guide, contextual-story and evidence-record systems. Canada gets regional subguides and a connected parent history, not one undifferentiated national culture. Aleutian chronology follows named places and documented changes. Original prose foregrounds people, activities, excavated findings and consequences. Caveats stay precise and attached to the claims they qualify. No automatic continuous occupation, ethnic continuity, exact routes or genocide inferred from cultural replacement.

Current application cutoff stays 1934. Existing later-date exceptions are not broadened. Existing record IDs are reused when appropriate; overlapping visits, founding events and archaeological phases are not added twice. All new historical records go to the shared map unless they are truly explanatory topic-only material. Coordinates use documented public places and honest precision. Restricted archaeological locations are not disclosed.

The previous batch left 66 additional Consensus tool calls. One comprehensive Deep dossier covers this request; count dispatch and polling conservatively in work/canada-aleutians/consensus-calls.json. Provider reports stay private. Verify actionable claims and imagery using primary publications, heritage institutions and Indigenous/community sources. Reuse only individually verified images (prefer public domain, CC0, CC BY); preserve their distinct licenses and avoid relicensing them under the atlas license. Links do not imply reuse permission.

Guides: data/site-guides.json + data/site-guide-content.json + src/*stories.ts; retain existing guide ownership using referenceRecordIds for reused records. Rendering: scripts/guide-enrichment.ts and scripts/site-guide-build.ts; attribution index enumerates all new sources.

Evidence work can proceed independently for eastern Canada, western/northern Canada and the Aleutians. Prose/media work targets existing guides and does not overwrite those regional proposal files. Parent alone merges shared arrays and release files. No subagent Consensus calls; budget is owned centrally.

Success means a demonstrably richer set of guide pages, connected regional Canadian and Aleutian histories, dated places visible in the shared map, clear per-image rights, accessible related links, and a verified release. It does not claim every known Canadian site has been mapped.
