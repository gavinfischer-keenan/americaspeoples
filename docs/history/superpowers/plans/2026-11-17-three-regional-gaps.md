# Three regional gaps implementation plan

**Goal:** Audit the current master map and fill three substantial region/time gaps: lower Central America before 1530, Atlantic coastal Brazil before 1500, and Solomon Islands/Vanuatu settlement and exchange after Lapita. The user's standing authority covers implementation and publication.

**Design:** Keep all new archaeological/local histories in the canonical shared dataset. Add three connected regional reading guides and contextual movies using the existing components. Research contributors prepare independent source-checked proposals in private folders; the primary agent integrates the release. No isolated topic map or invented continuous occupancy.
