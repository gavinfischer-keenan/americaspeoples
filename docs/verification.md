# Current source verification

Version **0.16.0 candidate**, prepared for review; not deployed. The [structured verification receipt](https://github.com/gavinfischer-keenan/americaspeoples/blob/feat/interior-frontiers/docs/releases/v0.16.0-verification.json) records commits, checks, research usage and review decisions. The previous live v0.15 deployment receipt remains in the repository.

The atlas contains **2,038 records: 1,980 shared and 58 focused**. This campaign adds 35 shared Amazon, Gran Chaco and Guianas observations, including five dated exchange connections and five conflicts or violent events. All new evidence stays within the shared 1934 endpoint. Consensus Deep cumulative usage is **66/100**, including polls; full generated reports remain private.

All **32 release-check stages passed** on the packaged implementation before two final source corrections. These checks included 285 unit tests, TypeScript, complete data validation, API and self-host startup, the entire workbook round-trip and all 2,038 imported review pages, historical playback, all topic movies, geography, tablet layout and browser error handling.

One independent whole-branch review found an ambiguous Cottica namesake incorrectly tied to an early date, and an unsupported outward trade arrow at Maripaston. Both were reproduced by failing tests and corrected in one pass. The final **287 unit tests passed**, followed by typechecking, 2,038-record validation, a rebuilt package, all five packaged-document checks, and the focused desktop/tablet map checks. All 35 corrected records match the published dataset, self-host dataset and SQLite exactly. The source guide in the package has the corrected dates and counts.

The map tests verify shared-context placement, route disappearance outside the dated activity window and conflict disappearance outside its event year. Earlier place markers remain labeled historical evidence. Schematic connections do not assert surveyed river itineraries. Geographic precision and unresolved source questions are described in [the interior evidence guide](interior-frontiers.html).

The Windows gate ran ten passing Python cases and skipped five Linux symlink-retention cases. No retention implementation changed. Browser checks use installed Edge on Windows; they are not a claim of physical-device testing or exhaustive coverage of every browser.

The reviewer checked selected underlying passages, not every historical source independently. No unresolved material findings or deferred minors remain. Research is incomplete: upper-river Guianas communities, Chaco seasonal places, and Cofán/Siona histories remain priorities. Blank map areas are collection gaps, not evidence of human absence. The [coverage audit](world-coverage-audit.html) preserves previous baselines and distinguishes observations from settlement counts.
