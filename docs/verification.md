# Current source verification

Version **0.22.0** adds Canadian and Aleutian regional histories and richer illustrated guides. It contains **2,480 records: 2,407 shared and 73 focused**, including 86 new shared observations. Nine new contextual movies add 81 chapters; the atlas now has 61 contextual stories, 27 independent topics, 59 guides and 95 available directory entries. Fifty place guides have registered terrain maps.

All **44 release stages passed**, including **361 unit tests**, TypeScript and data validation, the complete spreadsheet round-trip, all new contextual chapters, existing browser behaviour, media/source navigation and the extracted self-host package. Canada and the Arctic use taller terrain frames without stretching the geography.

One independent whole-branch review identified duplicate Amaknak and Quadra observations. The revisions preserve the existing IDs; four individual house-sample records keep their dates at the same Amaknak locality. Regression tests cover both reconciliations. A before-and-after ledger preserves all eight revised records, including Calvert’s public island locator. The review also checked 3,774 generated internal links and all 31 image hashes.

Twenty-two earlier guides gain 73 original source-linked paragraphs (5,552 words); each now exceeds 500 prose words. Twenty-five new photographs and museum-object images bring the collection to 31 images used in 32 guides. Each retains its individual credit and license. Reconstructed structures and museum objects are identified, and related-dive cards explain their connections. The source register distinguishes citation links from reused material.

One additional Consensus Deep dossier supported this release. Conservative lifetime usage is **92 tool calls**; **12 of the newly authorized 75 calls** have been used, leaving **63**. Reports remain private. Regional coverage is selected rather than exhaustive, and the shared cutoff remains 1934. Publication and live verification are recorded in [the release receipt](https://github.com/gavinfischer-keenan/americaspeoples/blob/main/docs/releases/v0.22.0-verification.json).
