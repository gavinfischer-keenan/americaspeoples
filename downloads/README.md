# Release downloads and withdrawn legacy bundles

Build the current source with `npm run build` to create the current self-host package in `release/`. Current project and third-party license notices travel with that package.

The v0.3.0–v0.6.0 ZIP bundles formerly stored in this directory included raw research reports whose public redistribution permission has not been established. They have been withdrawn from the current source tree and retained byte-for-byte in the owner's private archive. Historical checksum manifests are retained as provenance, not as current download offers. Earlier v0.1–v0.2 bundles remain as compatibility fixtures and have not been relicensed retroactively.

This change does not rewrite Git history, remove older tags, or erase copies previously downloaded or deployed. The current source and future packages use short access notices instead of the raw reports. See [reuse policy](../docs/reuse-and-contributing.md) and [third-party notices](../THIRD_PARTY.md).
